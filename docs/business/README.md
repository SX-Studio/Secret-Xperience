# Business documents

Investor- and fundraising-facing material. Not needed to run or deploy the platform.

| File | What it is |
|---|---|
| `INVESTOR_MEMORANDUM.md` | The information memorandum, source text. Marked *Confidential — for authorised recipients only*. |
| `INVESTOR_MEMORANDUM.pdf` | The same memorandum as sent out. |
| `pitch-deck.pdf` | The pitch deck. |

**These are confidential.** They sit in the repository, so everyone who can read the
repository can read them. Keep that in mind before widening who has access.
